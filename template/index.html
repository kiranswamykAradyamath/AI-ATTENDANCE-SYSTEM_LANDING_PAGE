How It Works

A simple attendance flow from setup to record

Teachers create the class, students join, and AI-assisted review keeps the final record clean.

01

Create a subject

Set the subject code, name, and section so attendance can be stored against the right class.

02

Share class access

Use the class link or QR code to help students join the correct subject quickly.

03

Verify students

Students use FaceID and teachers can run photo-based analysis to detect present students.

04

Confirm attendance

Review the generated report, then confirm and save the attendance result with confidence.
