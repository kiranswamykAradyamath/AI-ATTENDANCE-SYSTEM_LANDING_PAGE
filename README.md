# AI Attendance System Landing Page

A responsive Flask landing page for an AI-powered face recognition attendance system.

## Features

- Professional product landing page
- Mobile responsive navigation and layout
- Student and teacher workflow sections
- Screenshot gallery using local demo images
- Sticky navigation, animated counters, and reveal effects
- CTA links to the live Streamlit app

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5002/
```
